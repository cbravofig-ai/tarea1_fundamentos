# Gasto mensual en café

Calcula el gasto mensual estimado en café utilizando el precio promedio
observado en distintas cafeterías.

## Datos

Precios de café recopilados para fines educativos. 
- Archivo `data/raw/precio_cafe.csv`.

## Cómo correrlo

1. Abrir `tarea1_fundamentos.Rproj`.
2. Ejecutar `scripts/01_primeros_pasos.R`.
